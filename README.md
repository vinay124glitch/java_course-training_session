# Java Training 

Welcome to the **Java Training Repository**. This repository contains Java programs, examples, and exercises covering core and advanced Java concepts. It is designed for beginners and intermediate learners to strengthen their Java programming skills.

## 📚 Topics Covered

### Core Java
- Java Basics
- Variables and Data Types
- Operators
- Control Statements
- Loops
- Arrays
- Strings
- Methods
- Object-Oriented Programming (OOP)
  - Classes & Objects
  - Constructors
  - Inheritance
  - Polymorphism
  - Abstraction
  - Encapsulation

### Exception Handling
- try-catch-finally
- throw & throws
- Custom Exceptions

### Collections Framework
- List
- Set
- Map
- Queue
- Iterator

### File Handling
- Reading Files
- Writing Files
- Buffered Streams

### Multithreading
- Thread Class
- Runnable Interface
- Synchronization

### Java 8 Features
- Lambda Expressions
- Functional Interfaces
- Stream API
- Optional
- Method References

### JDBC
- Database Connectivity
- CRUD Operations

## 🛠 Prerequisites

- Java JDK 17 or later
- IDE (IntelliJ IDEA, Eclipse, or VS Code)
- Git

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/your-username/java-training.git
```

2. Navigate to the project

```bash
cd java-training
```

3. Compile a Java file

```bash
javac FileName.java
```

4. Run the program

```bash
java FileName
```
